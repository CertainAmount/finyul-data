# finyul-data

Figures, tables, primary-source lists and calculator code behind [finyul](https://finyul.com), a Korean site that checks personal-finance rules (tax, loans, pensions, insurance) against laws, official notices and press releases. Everything a finyul article draws or tabulates is published here so anyone can check the numbers and reuse them.

## What's here

- `data/<article>/` — for each article: its diagrams (`figure-N.svg`), its tables (`table-N.csv`, UTF-8), the primary sources it checked (`sources.csv`), and a README with the article link and the date the numbers refer to.
- `calc/` — the calculators used in the articles (acquisition tax, car tax, social insurance, health-insurance premiums and more), with the articles that use each one.

Article text is not copied here; read the explanation in each article. Table cells and diagram labels stay in Korean, as published.
